## Where to start

- [Basic concepts of positioning control](/en/concepts/positioning-basics) — a vendor-independent foundation; read it before diving into a specific module.
- [MELSEC Q — documentation hub](/en/q/) — catalogue of positioning modules and detail pages.
- [Commissioning the QD75D4](/en/q/qd75/commissioning) — the step-by-step procedure for bringing an axis into safe operation.

## Data principles

- Every parameter taken from the official manual cites the source `SH-080058` (Mitsubishi) in the source column or directly in the sentence.
- Measured values are filled in only when a real run on hardware has been performed; measurement tables are left empty by default.
- The Vietnamese and English editions mirror each other: same structure, same figures, same sources.

The Vietnamese edition of the handbook lives at the site root — for example this page has a Vietnamese version at `/`.
