# MELSEC Q high-speed counter modules — module list

<ModulePhoto id="qd62" />

[QD62](/en/q/modules/m/qd62) and [QD62E](/en/q/modules/m/qd62e) are two-channel pulse counter modules for encoders and pulse sensors, mounted on a MELSEC Q base and occupying 16 I/O points. They differ only in the output stage: QD62 is **sink**, QD62E is **source**; counting, buffer memory and programming are identical. The shared terminal table, specifications and wiring diagrams are on the [QD62 page](/en/q/modules/m/qd62).

## Module list

| Model | Role |
| --- | --- |
| [QD62](/en/q/modules/m/qd62) | Two-channel pulse counter, sink output type |
| [QD62E](/en/q/modules/m/qd62e) | Two-channel pulse counter, source output type |
