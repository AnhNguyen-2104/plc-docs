# MELSEC Q CC-Link modules — module list

<ModulePhoto id="qj61bt11n" />

The [QJ61BT11N](/en/q/modules/m/qj61bt11n) is a CC-Link master/local module mounted on the MELSEC Q base, exchanging cyclic data with up to 64 stations on one RS-485 bus. The module acts as master when its station number is 0, or as a local station with a station number of 1–64. This page lists the CC-Link model; specifications, terminals, switches and cabling rules are on its model page.
