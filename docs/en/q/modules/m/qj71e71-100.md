## 1. Signal groups to wire

QJ71E71-100 is a 100BASE-TX/10BASE-T Ethernet module. The signal groups to wire are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Network cable | RJ45 (RD/SD pairs) | bidirectional | Fixed MDI interface (SH-080009 §3.2 p.29) |
| Status LEDs | RUN, INIT., OPEN, SD, RD, ERR., COM.ERR., 100M | — | Observe on the module face (SH-080009 §2 p.27) |
| Module supply | 5 VDC from base | base → module | 0.50 A (SH-080009 §3.2 p.29) |
| Network address | IP, subnet, port | — | Set in configuration, not wired |

## 2. Wiring principles

- **Connection type:** RJ45 connector — RJ45 port 100BASE-TX/10BASE-T (SH-080009 §3.2, p. 29).
- Straight-through cable to a hub/switch; a direct PC–module link needs a crossover cable or an auto-MDI port because the interface is fixed MDI (SH-080009 §3.2 p.29).
- Maximum segment length is 100 m between hub and node (SH-080009 §3.2 p.29).
- The station IP must share class/subnet with the connected device; subnet mask must match (SH-080009 §7.1.3 (2) p.88).
- The station port must be outside 1388H–138AH (SH-080009 §7.1.4 p.89).
- Route network cable away from power wiring; do not bundle it with supply cables.

## 5. External device connections

- External devices: PC, HMI, other Ethernet modules or a router through a hub/switch.
- Straight-through cable for a hub/switch; crossover cable for a direct PC–module link without auto-MDI.
- Enable KeepAlive or Ping for TCP connections; check for duplicate IP before opening.

### LEDs and buffers

| LED | Meaning |
| --- | --- |
| `RUN` | ON: normal operation; OFF: an error has occurred |
| `INIT.` | ON: initial process completed; OFF: not processed |
| `OPEN` | ON: at least one connection is open |
| `SD` | Flashing: data being sent |
| `ERR.` | ON: incorrect setting |
| `COM.ERR.` | ON: communication error; does not turn off when the cause is removed |
| `RD` | ON: data being received |
| `100M` | ON: 100 Mbps; OFF: 10 Mbps or no cable |

| Address | Content | Source |
| --- | --- | --- |
| `5000H` | Open completion signal, bits b0–b15 = connections 1–16 | SH-080009 §3.5.2 p.50 |

| `680H` | Fixed buffer No.1 — data length | SH-080009 §3.5.2 p.49 |
| `681H`–`A7FH` | Fixed buffer No.1 — data | SH-080009 §3.5.2 p.49 |
| `78H` | Connection No.1 — own station port | SH-080009 §3.5.2 p.42 |
| `79H`–`7AH` | Connection No.1 — destination IP | SH-080009 §3.5.2 p.42 |
| `7BH` | Connection No.1 — destination port | SH-080009 §3.5.2 p.42 |

## 6. Checklist before power-up

- [ ] No IP conflict on the same subnet.
- [ ] Module IP shares class/subnet with the HMI/PC; subnet mask matches.
- [ ] Straight-through cable to a hub/switch; direct PC–module link uses crossover or auto-MDI.
- [ ] KeepAlive or Ping is configured for the TCP connection.
- [ ] Station port is outside 1388H–138AH.
- [ ] INIT. ON before opening; OPEN ON after opening.
- [ ] SD/RD LEDs checked during send/receive.
- [ ] Network cable is separated from power wiring.
