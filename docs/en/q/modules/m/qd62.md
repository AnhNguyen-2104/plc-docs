## 1. Signal groups to wire

QD62/QD62E are two-channel pulse counter modules. The signal groups to wire are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Count pulses | Phase A, Phase B | encoder → module | Each channel has three 24/12/5 V pairs; wire one pair only (SH-080036 §3.5 p.3-12) |
| Control | Preset, Function start | switch/PLC → module | Same three 24/12/5 V levels (SH-080036 §3.5 p.3-12) |
| Comparator output | EQU1, EQU2 | module → load | 0.5 A/point, 2 A/common; QD62 sink, QD62E source (SH-080036 §3.5 p.3-12) |
| External supply | 12/24 V, 0 V | supply → module | Feeds the output stage (SH-080036 §3.5 p.3-12) |

### Counting methods

| Mode | Description | Source |
| --- | --- | --- |
| 1-phase x1 | Counts rising edges of phase A; direction is set by phase B or the down-count command | SH-080036 §5.1.1 p.5-1 |
| 1-phase x2 | Counts both edges of phase A | SH-080036 §5.1.1 p.5-1 |
| CW/CCW | CW pulses on phase A count up, CCW pulses on phase B count down | SH-080036 §5.1.1 p.5-1 |
| 2-phase x1 | One edge per A/B cycle | SH-080036 §5.1.1 p.5-1 |
| 2-phase x2 | Two edges per A/B cycle | SH-080036 §5.1.1 p.5-1 |
| 2-phase x4 | Four edges per A/B cycle | SH-080036 §5.1.1 p.5-1 |

## 2. Wiring principles

- **Connection type:** 40-pin connector (A20/B20) — two rows A20/B20, 32 points per connector (SH-080036 §3.5, p. 3-12).
- Each channel has three 24 V, 12 V and 5 V pin pairs; wire exactly one pair to match the encoder level. The wrong pair loses pulses or damages the input.
- ABCOM is the common of the A/B pair, not the 0 V supply for the external load.
- Use shielded twisted pair for A and B; ground the shield at one point on the encoder side.
- Keep pulse wiring at least 150 mm from power wiring; noise causes miscounts.
- QD62 and QD62E differ in output direction: QD62 sinks (load to the positive supply), QD62E sources (load to 0 V).

## 3. Reference diagram

- QD62 is the two-channel counter reference. [QD62E](/en/q/modules/m/qd62e) shares the pin table and counting, differing only in the source output stage.
- Do not apply the QD62D pinout (RS-422-A differential inputs) to QD62/QD62E.
- QD62/QD62E have no dedicated Z input; route the Z pulse to an ordinary digital input or external preset logic.

## 6. Checklist before power-up

- [ ] Power was switched off before wiring.
- [ ] Only one 24/12/5 V pulse pair is wired per channel.
- [ ] ABCOM is not used as the load 0 V.
- [ ] Encoder type is correct: open collector or line driver.
- [ ] Pulse wiring is at least 150 mm from power wiring.
- [ ] Shield grounded at one end on the encoder side.
- [ ] Pulses were checked by turning the encoder shaft slowly.
- [ ] Sink/source output stage is wired in the correct direction.
