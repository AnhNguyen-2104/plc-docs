## 1. Signal groups to wire

QD75P4 is a four-axis positioning module with open-collector pulse outputs. The signal groups to wire are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Command pulse | PULSE F, PULSE R | QD75 → driver | Open-collector outputs; F = forward, R = reverse (SH-080058 §3.4) |
| Functional input | DOG, FLS, RLS, STOP, CHG | driver/switch → QD75 | Same functional-input group as QD75D4 (SH-080058 §3.4.4) |
| Common | Input-group COM | — | Common for the functional-input group (SH-080058 §3.4.4) |
| Deviation clear | CLEAR, CLEAR COM | QD75 → driver | Wire only when position deviation must be cleared (SH-080058 §3.4) |
| READY | READY, RDYCOM | driver → QD75 | Required for the READY loop (SH-080058 §3.4) |
| Module supply | 5 VDC from base | base → module | Taken from the base 5 V rail |

## 2. Wiring principles

- **Connection type:** 40-pin connector (A20/B20) — 40-pin connector for drive and external signals (SH-080058 §3.4.2, p. 3-25).
- The pulse outputs are open collector, not differential; check the driver current-limiting resistor and voltage level in SH-080058 §3.4 before wiring.
- Each axis has its own terminal block; label wires by axis to avoid confusion during maintenance.
- Route pulse wiring away from the servo power cable; use shielded cable with one-end grounding.
- A maximum of 2 wires per terminal point; no intermediate wires.
- Keep pulse cable length within the SH-080058 §3.4 limit.

## 3. Reference diagram

- Use [QD75D4](/en/q/modules/m/qd75d4) for the terminal layout, axis numbering and functional-input group. The layout and DOG/FLS/RLS/STOP/CHG part apply.
- Do not apply the QD75D4 differential PULSE F+/F−, R+/R− pairs or its differential output circuit; QD75P4 uses open collector.
- Do not apply the SSCNET driver scheme of [QD75M1](/en/q/modules/m/qd75m1) or [QD77MS4](/en/q/modules/m/qd77ms4).

- Wire PULSE F/R open collector to the driver pulse input; for a differential-only driver, use an open-collector-to-differential converter per the driver manual.
- Wire DOG/FLS/RLS/STOP/CHG as the machine requires; if FLS/RLS are not wired, disable them in parameters.
- Label both ends of each wire and mark the axis before bundling.

## 6. Checklist before power-up

- [ ] Power was cut throughout the wiring process.
- [ ] Correct axis and correct PULSE F/R direction.
- [ ] Driver current-limiting resistor/voltage level checked against the open-collector output.
- [ ] READY and RDYCOM wired to the correct driver for each axis.
- [ ] No more than 2 wires per terminal point.
- [ ] Pulse wires separated from power wires.
- [ ] Shield grounded at one end.
- [ ] Pin numbers cross-checked against SH-080058.
- [ ] Hard limit switches and emergency stop wired independently of the PLC.
