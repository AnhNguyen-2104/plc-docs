## 1. Signal groups to wire

QJ71C24N has two independent serial channels. The signal groups to wire are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| CH1 RS-232 | CD, RD, SD, ER, SG, DR, RS, CS, CI | bidirectional | 9-pin female D-sub, M2.6 thread (SH-080006 §3.2.1 p.3-3) |
| CH2 RS-422/485 | SDA, SDB, RDA, RDB, SG, (FG) | bidirectional | Two-piece terminal block (SH-080006 §4.4.2 p.4-8) |
| Terminating resistor | 330 ohm / 110 ohm | — | Only at the two end stations (SH-080006 §4.4.2 p.4-9) |
| Module supply | 5 VDC from base | base → module | Taken from the base 5 V rail |

### CH1 RS-232 (D-sub 9)

| Pin | Signal | Full name | Direction (module side) | Function |
| --- | --- | --- | --- | --- |
| 1 | `CD` | CD(DCD) | in | Carrier detect; can be ignored via the CD terminal check setting |
| 2 | `RD` | RD(RXD) | in | Receive data |
| 3 | `SD` | SD(TXD) | out | Transmit data |
| 4 | `ER` | ER(DTR) | out | Ready to receive (when DTR/DSR control is used) |
| 5 | `SG` | SG | — | Signal ground |
| 6 | `DR` | DR(DSR) | in | External device ready; the module does not transmit while this signal is OFF |
| 7 | `RS` | RS(RTS) | out | Request to send |
| 8 | `CS` | CS(CTS) | in | Clear to send; the module does not transmit while this signal is OFF |
| 9 | `CI` | CI(RI) | in | Modem ring indicator, connected only when a modem is used |

### CH2 RS-422/485

| Terminal | Signal | 4-wire | 2-wire (RS-485) |
| --- | --- | --- | --- |
| `SDA` | Transmit data A | to external `RDA` | tied to `RDA`, runs on wire A |
| `SDB` | Transmit data B | to external `RDB` | tied to `RDB`, runs on wire B |
| `RDA` | Receive data A | to external `SDA` | tied to `SDA` |
| `RDB` | Receive data B | to external `SDB` | tied to `SDB` |
| `SG` | Signal ground | to external `SG` | to external `SG` |
| `(FG)` | Frame ground | per panel rules | per panel rules |

## 2. Wiring principles

- **Connection type:** D-sub 9 (CH1) + RS-422/485 terminal block (CH2) — CH1 D-sub 9, CH2 6-point RS-422/485 block (SH-080006 §3.2.1, p. 3-3).
- Run SDA/SDB and RDA/RDB as pairs, never split (SH-080006 §4.4.2 (1)(b)3 p.4-8).
- Fit the correct terminating resistor only at the two end stations; never at an intermediate station.
- Ground the shield at one end; connect it between both FG terminals only if noise persists.
- Keep signal cable at least 100 mm from power wiring (SH-080006 §4.4 (6) p.4-5).

### Terminating resistors

| Transmission type | Resistor | Rating | Fitted at |
| --- | --- | --- | --- |
| RS-422 | 330 ohm | 1/4 W | The two stations at both ends of the circuit |
| RS-485 | 110 ohm | 1/2 W | The two stations at both ends of the circuit |

| b3 | Even/odd parity | Odd | Even |
| b4 | Stop bit | 1 | 2 |
| b5 | Sum check code | No | Yes |
| b6 | Write during RUN | Prohibited | Allowed |
| b7 | Setting modifications | Prohibited | Allowed |

## 5. External device connections

- Connect RS-232 devices 1:1 through the D-sub 9, maximum 15 m (SH-080006 §3.1 p.3-2).
- Connect RS-422/485 devices in 4-wire or 2-wire; maximum line length is 1200 m (SH-080006 §3.1 p.3-2).
- Use 330 ohm for RS-422 and 110 ohm for RS-485 at the two end stations.
- Station numbers must be unique; set 0 for a 1:1 link (SH-080006 §4.5.2 (1)(d) p.4-18).

### Buffer areas and handshake signals

| Area | CH1 | CH2 | First word | Notes |
| --- | --- | --- | --- | --- |
| Transmission area | `400H`–`5FFH` | `800H`–`9FFH` | `400H` / `800H` | First word = number of words to send |
| Receive area | `600H`–`7FFH` | `A00H`–`BFFH` | `600H` / `A00H` | First word = number of words received |

| Signal | Meaning |
| --- | --- |
| `X0` / `X1` | CH1 transmission completed normally / transmission error |
| `X3` / `X4` | CH1 reception data read request / reception error detected |
| `Y0` / `Y1` | CH1 transmission request / reception data read completed |
| `X1E` | Module ready (accessible) |

## 6. Checklist before power-up

- [ ] Terminating resistors are only at the two end stations, never in the middle.
- [ ] Resistor value matches the type: 330 ohm for RS-422, 110 ohm for RS-485.
- [ ] Shield grounded at one end.
- [ ] SDA/SDB and RDA/RDB run as pairs, never split.
- [ ] 2-wire or 4-wire matches the echo-back setting and the external device.
- [ ] Station numbers are unique; set 0 for 1:1.
- [ ] Rate, data bits, parity and stop bits match at both ends.
- [ ] Signal cable is at least 100 mm from power wiring.
- [ ] Loopback test was run before connecting the real device.
