## 1. Signal groups to wire

QX40 is a 16-point 24 VDC input module with positive common. COM is tied to +24 V and an NPN sensor pulls each X point to 0 V. The manufacturer's terminal block table TB1–TB18:

The QX40 terminal block runs TB1–TB16 for X0–XF, TB17 is COM shared by all 16 points, and TB18 is vacant. MELSEC Q numbers X/Y devices in hexadecimal, so XA follows X9 and the last point of a 16-point module is XF.

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Input | X0…XF | sensor/switch → module | 16 points, 24 VDC, approx. 4 mA/point (SH-080042 §2.4 p.2-4) |
| Common | COM (TB17) | — | Tied to +24 V; NPN pulls X to 0 V (SH-080042 §2.4 p.2-4) |
| Vacant terminal | TB18 | — | Not used (SH-080042 §2.4 p.2-4) |
| Module supply | 5 VDC from base | base → module | 50 mA with all points ON (SH-080042 §2.4 p.2-4) |

## 2. Wiring principles

- **Connection type:** screw terminal block — 18 M3 screw points, one wire per point (SH-080042 §2.4, p. 2-4).
- COM must go to +24 V; reversed polarity will never turn an input on.
- Use the TB1–TB18 screw terminal block; one wire per X point, no intermediate wires.
- Route signal wiring at least 100 mm from power wiring; if they must share a bundle, use shielded cable and ground the shield on the PLC side (SH-080483 §4.8.2 p.111).
- Feed the sensor 24 VDC from a separate branch and fuse, not from the base 5 V rail.
- Tighten the M3 terminals to 0.42–0.58 N·m (SH-080042 §1.2.6 p.1-17).

## 5. External device connections

- Wire an NPN open-collector sensor or dry contact between the X point and 0 V; COM goes to +24 V.
- Check the sensor supply voltage at the terminal, after cable drop, against 24 VDC +20/−15 %.
- Use shielded twisted pair for remote sensors; ground the shield at one end in the PLC panel.
- With two-wire sensors, check the OFF leakage current so it cannot hold the input ON.

## 6. Checklist before power-up

- [ ] Power was switched off before wiring.
- [ ] COM (TB17) is wired to +24 V, not 0 V.
- [ ] Sensor type is correct: NPN or dry contact.
- [ ] The 24 VDC supply is within +20/−15 %.
- [ ] Every point X0…XF was tested by hand before automatic operation.
- [ ] Signal wiring is at least 100 mm from power wiring.
- [ ] Shield grounded at one end, per panel rules.
- [ ] No multiple wires in one terminal; M3 terminals tightened correctly.
