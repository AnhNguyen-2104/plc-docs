## 1. Signal groups to wire

QX80 is a 16-point 24 VDC input module with negative common. COM is tied to 0 V and a PNP sensor drives each X point to +24 V. The signal groups to wire are:

| --- | --- | --- | --- |
| Input | X0…XF | sensor/switch → module | 16 points, 24 VDC, approx. 4 mA/point (SH-080042 §2.18 p.2-24) |
| Common | COM | — | Tied to 0 V; PNP drives X to +24 V (SH-080042 §2.18 p.2-24) |
| Module supply | 5 VDC from base | base → module | Taken from the base 5 V rail; never connect a 24 V supply to this rail |

## 2. Wiring principles

- **Connection type:** screw terminal block — 18 M3 screw points, one wire per point (SH-080042 §2.18, p. 2-24).
- COM must go to 0 V; reversed polarity will never turn an input on.
- Use the screw terminal block; terminal layout per SH-080042 §2.18.
- Route signal wiring at least 100 mm from power wiring; if they must share a bundle, use shielded cable and ground the shield on the PLC side (SH-080483 §4.8.2 p.111).
- Feed the sensor 24 VDC from a separate branch and fuse, away from the power supply.
- Do not stuff multiple wires into one terminal; keep one wire per X point.

## 5. External device connections

- Wire a PNP open-collector sensor or dry contact between +24 V and the X point; COM goes to 0 V.
- Check the sensor supply voltage at the terminal, after cable drop, against 24 VDC +20/−15 %.
- Use shielded twisted pair for remote sensors; ground the shield at one end in the PLC panel.
- With two-wire sensors, check the OFF leakage current so it cannot hold the input ON.

## 6. Checklist before power-up

- [ ] Power was switched off before wiring.
- [ ] COM is wired to 0 V, not +24 V.
- [ ] Sensor type is correct: PNP or dry contact.
- [ ] The 24 VDC supply is within +20/−15 %.
- [ ] Every point X0…XF was tested by hand before automatic operation.
- [ ] Signal wiring is at least 100 mm from power wiring.
- [ ] Shield grounded at one end, per panel rules.
- [ ] No multiple wires in one terminal; terminals tightened correctly.
