## 1. Signal groups to wire

QI60 is a 16-point 24 VDC input module. This is a 24 VDC interrupt input module; the common and interrupt conditions are in SH-080042 §5-1. The signal groups to wire are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Input | X0…XF | sensor/switch → module | 16 points, 24 VDC; terminal table in SH-080042 §5-1 |
| Common | COM | — | Per §5-1; do not infer from a standard input module |
| Module supply | 5 VDC from base | base → module | Taken from the base 5 V rail; never connect a 24 V supply to this rail |

## 2. Wiring principles

- **Connection type:** screw terminal block — 18 M3 screw points, one wire per point (SH-080042 §5.1, p. 5-2).
- Follow §5-1 for the common and interrupt direction; do not copy a standard input module.
- Route signal wiring at least 100 mm from power wiring; if they must share a bundle, use shielded cable and ground the shield on the PLC side (SH-080483 §4.8.2 p.111).
- Feed the sensor 24 VDC from a separate branch and fuse, not from the base 5 V rail.
- Do not stuff multiple wires into one terminal; keep one wire per X point.

## 5. External device connections

- The interrupt source is a dry contact or 24 VDC sensor; pulse width and interrupt conditions are in SH-080042 §5-1.
- Use shielded twisted pair for the interrupt source; ground the shield at one end in the PLC panel.
- Do not share COM with standard inputs if §5-1 specifies a separate common.

## 6. Checklist before power-up

- [ ] Power was switched off before wiring.
- [ ] common and interrupt conditions per §5-1 is correct.
- [ ] Sensor type is correct: 24 VDC interrupt source.
- [ ] Supply voltage is within the module rated range of 24 VDC.
- [ ] Every point was tested by hand before automatic operation.
- [ ] Signal wiring is at least 100 mm from power wiring.
- [ ] Shield grounded at one end, per panel rules.
- [ ] No multiple wires stuffed into one terminal.
