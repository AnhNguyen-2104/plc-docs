## 1. Signal groups to wire

Q612B is a extension base with 12 slots. The base has no field signal terminals; the groups to check are:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| I/O module slots | 12 slots | module ↔ base | Modules only; no field signal wiring |
| Extension connector | Extension cable | main base ↔ extension base | Extension base needs its own power module |
| Power | Dedicated power module | power module → base | Supplies the 5 V rail |
| Ground | FG screw | — | Ground to the panel at ≤100 ohm |
| Mounting | M4 screw holes | — | 98 mm high, 44.1 mm deep |

## 2. Wiring principles

- **Connection type:** no field terminals; module slots — module slots only, no field terminals (SH-080483 §8.1, p. 242).
- Do not wire field signals to the base; all I/O goes through modules plugged into the slots.
- Keep covers on empty slots and do not touch the bus connector while power is on.
- Tighten the M4 base screws correctly; keep the power module/CPU ventilation clear.
- An extension base needs its own power module; do not feed its 5 V rail from the main base.
- Insert the extension cable fully and lock it; connect the FG screw to the panel earth.

## 3. Reference diagram

- Main base: use [Q312B](/en/q/modules/m/q312b) for the power/CPU and I/O slot arrangement; the seating method applies, the 12-slot count does not apply to other models.

## 5. External device connections

- External devices do not connect to the base; sensors, loads, drives and network cables connect to the module in the relevant slot.
- An extension base takes power from its own power module and links to the main base through the extension cable.
- The base FG screw connects to the panel earth; never use it as the 0 V of a 24 VDC supply.

## 6. Checklist before power-up

- [ ] Power was switched off before mounting the base.
- [ ] Base is fixed with M4 screws and does not rock.
- [ ] Power module and CPU are in the correct positions with locks engaged.
- [ ] Covers are fitted to all empty slots.
- [ ] Extension cable is fully inserted and locked.
- [ ] Extension base has its own power module.
- [ ] FG screw is grounded to the panel, ≤100 ohm.
- [ ] Module count does not exceed 12 slots.
