## 1. Signal groups to wire

QJ71C24N-R4 has two RS-422/485 channels. Each channel uses the same terminal set:

| Group | Signal | Direction | Notes |
| --- | --- | --- | --- |
| Transmit | SDA, SDB | module → external device | Differential transmit pair (SH-080006 §3.1 p.3-1) |
| Receive | RDA, RDB | external device → module | Differential receive pair (SH-080006 §3.1 p.3-1) |
| Common | SG | — | Signal ground (SH-080006 §3.1 p.3-1) |
| Frame ground | (FG) | — | Panel ground; tied to SLD inside the module (SH-080006 §4.4.2 p.4-8) |

| Terminal | Signal | 4-wire | 2-wire (RS-485) |
| --- | --- | --- | --- |
| SDA | Transmit data A | to external RDA | tied to RDA, wire A |
| SDB | Transmit data B | to external RDB | tied to RDB, wire B |
| RDA | Receive data A | to external SDA | tied to SDA |
| RDB | Receive data B | to external SDB | tied to SDB |
| SG | Signal ground | to external SG | to external SG |
| (FG) | Frame ground | per panel rules | per panel rules |

## 2. Wiring principles

- **Connection type:** RS-422/485 terminal blocks (CH1, CH2) — two 6-point RS-422/485 blocks (SH-080006 §3.3, p. 3-7).
- Run SDA/SDB and RDA/RDB as pairs, never split (SH-080006 §4.4.2 (1)(b)3 p.4-8).
- Fit 330 ohm for RS-422 or 110 ohm for RS-485 terminating resistors only at the two end stations (SH-080006 §4.4.2 (1)(c) p.4-9).
- Ground the shield at one end; connect it between both FG terminals only if noise persists (SH-080006 §4.4 p.4-5).
- Keep signal cable at least 100 mm from power wiring (SH-080006 §4.4 (6) p.4-5).
- The 2-wire or 4-wire setting must match the echo-back setting and the external device (SH-080006 §3.3.4 p.3-12).

## 3. Reference diagram

- Use [QJ71C24N](/en/q/modules/m/qj71c24n) for the CH2 terminal table, 4-wire diagram and terminating resistors. It applies verbatim to both -R4 channels.
- Do not apply the QJ71C24N CH1 RS-232 D-sub 9 channel; -R4 has no RS-232 channel.
- [QJ71E71-100](/en/q/modules/m/qj71e71-100) is Ethernet and does not apply to an RS-422/485 line.

## 5. External device connections

- Use shielded twisted pair for each SDA/SDB and RDA/RDB pair.
- A 4-wire RS-422 device crosses SDA→RDA and RDA→SDA; a 2-wire RS-485 link ties SDA to RDA and SDB to RDB.
- Fit 330 ohm or 110 ohm only at the two end stations, never at an intermediate station.
- Maximum RS-422/485 distance is 1200 m for the whole line (SH-080006 §3.1 p.3-2).

## 6. Checklist before power-up

- [ ] Power was switched off before wiring.
- [ ] SDA/SDB and RDA/RDB run as pairs.
- [ ] Terminating resistors have the correct value and are only at both ends.
- [ ] 2-wire or 4-wire matches the echo-back setting.
- [ ] Shield grounded at one end.
- [ ] Signal cable is at least 100 mm from power wiring.
- [ ] Station numbers are unique on the line.
- [ ] Loopback test was run before connecting the real device.
