# MELSEC Q Ethernet modules — module list

<ModulePhoto id="qj71e71-100" />

The [QJ71E71-100](/en/q/modules/m/qj71e71-100) is an Ethernet module mounted on the MELSEC Q base, communicating with PCs, HMIs, other Ethernet modules or external devices through an RJ45 port. The module holds 16 logical connections and fixed buffers in its buffer memory. This page lists the Ethernet model of the group; specifications, wiring, IP/port settings and the open/close/send/receive instructions are on its model page.

## Module list

| Model | Role |
| --- | --- |
| [QJ71E71-100](/en/q/modules/m/qj71e71-100) | 100BASE-TX/10BASE-T Ethernet module |
