# Module đếm xung MELSEC Q — danh sách module

<ModulePhoto id="qd62" />

[QD62](/q/modules/m/qd62) và [QD62E](/q/modules/m/qd62e) là module đếm xung 2 kênh cho encoder và cảm biến xung, gắn trên base MELSEC Q và chiếm 16 điểm I/O. Hai bản khác nhau ở kiểu tầng ra: QD62 là **sink**, QD62E là **source**; phần đếm, bộ đệm và cách lập trình giống nhau. Bảng chân, thông số và sơ đồ đấu dây dùng chung nằm ở [trang QD62](/q/modules/m/qd62).

## Danh sách module

| Model | Vai trò |
| --- | --- |
| [QD62](/q/modules/m/qd62) | Đếm xung 2 kênh, ngõ ra kiểu sink |
| [QD62E](/q/modules/m/qd62e) | Đếm xung 2 kênh, ngõ ra kiểu source |
