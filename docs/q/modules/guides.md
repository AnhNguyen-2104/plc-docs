# Hướng dẫn các module

<ModuleSectionNav />

Bảng dưới liệt kê toàn bộ module Q-series, chia theo nhóm chức năng. Bấm tên model để mở trang riêng: ảnh hãng, số điểm, dòng 5 V, manual kèm số trang và quy tắc đấu dây theo nhóm. Trang model không chép lại bảng đầu cực; bảng chân chi tiết nằm ở trang nhóm hoặc đúng mục manual ghi trên trang.
