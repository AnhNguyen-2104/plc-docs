## 1. Nhóm tín hiệu cần đấu

QJ71E71-100 là module Ethernet 100BASE-TX/10BASE-T. Các nhóm tín hiệu cần đấu:

| Nhóm | Tín hiệu | Hướng | Ghi chú |
| --- | --- | --- | --- |
| Cáp mạng | RJ45 (cặp RD/SD) | hai chiều | Giao diện cố định MDI (SH-080009 §3.2 p.29) |
| Đèn trạng thái | RUN, INIT., OPEN, SD, RD, ERR., COM.ERR., 100M | — | Quan sát mặt module (SH-080009 §2 p.27) |
| Nguồn module | 5 VDC từ base | base → module | 0,50 A (SH-080009 §3.2 p.29) |
| Địa chỉ mạng | IP, subnet, port | — | Cài trong cấu hình, không đấu dây |

| Hạng mục | Giá trị | Nguồn |
| --- | --- | --- |

## 2. Nguyên tắc đi dây

- **Kiểu kết nối:** đầu nối RJ45 — cổng RJ45 100BASE-TX/10BASE-T (SH-080009 §3.2, p. 29).
- Cáp thẳng tới hub/switch; nối trực tiếp PC–module cần cáp chéo hoặc cổng tự đảo cực vì giao diện cố định MDI (SH-080009 §3.2 p.29).
- Chiều dài segment tối đa 100 m giữa hub và node (SH-080009 §3.2 p.29).
- IP của trạm phải cùng class/subnet với thiết bị kết nối; subnet mask khớp (SH-080009 §7.1.3 (2) p.88).
- Port trạm không nằm trong dải cấm 1388H–138AH (SH-080009 §7.1.4 p.89).
- Cáp mạng đi cách dây động lực; không bó chung với dây nguồn.

## 3. Sơ đồ tham chiếu

- QJ71E71-100 là trang mẫu Ethernet RJ45. [QJ71C24N](/q/modules/m/qj71c24n) là nối tiếp RS-232/422; chỉ đối chiếu cách ly và bố trí module, không áp dụng bảng chân.
- [QJ61BT11N](/q/modules/m/qj61bt11n) là bus CC-Link RS-485; không áp dụng cáp RJ45.
- Cấu hình IP/cổng ở mục 2, không phải đấu dây.

## 5. Đấu nối thiết bị ngoài

- Thiết bị ngoài: PC, HMI, module Ethernet khác hoặc router qua hub/switch.
- Cáp thẳng cho hub/switch; cáp chéo khi nối trực tiếp PC–module và không có cổng tự đảo cực.
- Đặt KeepAlive hoặc Ping cho kết nối TCP; kiểm tra IP trùng trước khi mở kết nối.

### LED và vùng đệm

| LED | Ý nghĩa |
| --- | --- |
| `RUN` | ON: hoạt động bình thường; OFF: có lỗi |
| `INIT.` | ON: khởi tạo xong; OFF: chưa xử lý |
| `OPEN` | ON: có ít nhất một kết nối đã mở |
| `SD` | Nhấp nháy: đang phát dữ liệu |
| `ERR.` | ON: cài đặt sai |
| `COM.ERR.` | ON: lỗi truyền thông; không tự tắt khi hết nguyên nhân |
| `RD` | ON: đang nhận dữ liệu |
| `100M` | ON: 100 Mbps; OFF: 10 Mbps hoặc chưa nối cáp |

| Địa chỉ | Nội dung | Nguồn |

| `5005H` | Fixed buffer reception status signal, bit b0–b15 | SH-080009 §3.5.2 p.50 |
| `680H` | Fixed buffer No.1 — data length | SH-080009 §3.5.2 p.49 |
| `681H`–`A7FH` | Fixed buffer No.1 — data | SH-080009 §3.5.2 p.49 |
| `78H` | Connection No.1 — port của trạm | SH-080009 §3.5.2 p.42 |
| `79H`–`7AH` | Connection No.1 — IP đích | SH-080009 §3.5.2 p.42 |
| `7BH` | Connection No.1 — port đích | SH-080009 §3.5.2 p.42 |

## 6. Checklist trước khi cấp điện

- [ ] Không trùng IP với thiết bị khác trên cùng subnet.
- [ ] IP module cùng class/subnet với HMI/PC; subnet mask khớp.
- [ ] Cáp thẳng tới hub/switch; nối trực tiếp PC–module dùng cáp chéo hoặc cổng tự đảo cực.
- [ ] Đã đặt KeepAlive hoặc Ping cho kết nối TCP.
- [ ] Port trạm ngoài dải cấm 1388H–138AH.
- [ ] INIT. ON trước khi mở kết nối; OPEN ON sau khi mở.
- [ ] Đã kiểm tra LED SD/RD khi truyền/nhận.
- [ ] Cáp mạng cách dây động lực.
