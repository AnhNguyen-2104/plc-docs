# Module CC-Link MELSEC Q — danh sách module

<ModulePhoto id="qj61bt11n" />

[QJ61BT11N](/q/modules/m/qj61bt11n) là module master/local của CC-Link gắn trên base MELSEC Q, trao đổi dữ liệu cyclic với tối đa 64 trạm trên một tuyến bus RS-485. Module đóng vai trò master khi số trạm bằng 0, hoặc local khi có số trạm 1–64. Trang này liệt kê model CC-Link; thông số, đầu cực, công tắc và checklist đấu tuyến nằm ở trang model.

## Danh sách module

| Model | Vai trò |
| --- | --- |
| [QJ61BT11N](/q/modules/m/qj61bt11n) | Module master/local CC-Link |

## 1. Các module truyền thông khác

| Model | Vai trò |
| --- | --- |
| [QJ71C24N](/q/modules/m/qj71c24n) | Hai kênh nối tiếp: RS-232 và RS-422/485 |
| [QJ71C24N-R4](/q/modules/m/qj71c24n-r4) | Hai kênh nối tiếp RS-422/485 |
| [QJ71E71-100](/q/modules/m/qj71e71-100) | Module Ethernet 100BASE-TX/10BASE-T |
| [QJ71LP21-25](/q/modules/m/qj71lp21-25) | Module mạng vòng quang MELSECNET/H |

## 2. Đọc tiếp

- Tham số mạng, auto refresh và chương trình mẫu: SH-080016 chương 6 và 9–11.
- Tra mã lỗi và chẩn đoán CC-Link: SH-080016 chương 13.
- Các module khác của họ Q: [MELSEC Q](/q/).
