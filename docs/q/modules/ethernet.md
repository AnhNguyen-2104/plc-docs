# Module Ethernet MELSEC Q — danh sách module

<ModulePhoto id="qj71e71-100" />

[QJ71E71-100](/q/modules/m/qj71e71-100) là module Ethernet gắn trên base MELSEC Q, giao tiếp với PC, HMI, module Ethernet khác hoặc thiết bị ngoài qua cổng RJ45. Module giữ 16 kết nối logic và các vùng đệm cố định trong buffer memory. Trang này liệt kê model Ethernet của nhóm; thông số, đấu nối, cài đặt IP/cổng và các lệnh mở/đóng/gửi/nhận nằm ở trang model.

## Danh sách module

| Model | Vai trò |
| --- | --- |
| [QJ71E71-100](/q/modules/m/qj71e71-100) | Module Ethernet 100BASE-TX/10BASE-T |

| Model | Vai trò |
